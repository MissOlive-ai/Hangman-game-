# ☁️ Cloud Computing Hangman Game

An interactive, client-side Hangman game with a cloud computing theme, featuring polished styling, animations, and social sharing capabilities.

## 🎮 Features

- **Cloud Computing Theme**: 50+ cloud computing terms including Kubernetes, Docker, AWS, Azure, and more
- **Interactive Gameplay**: Click letters or use keyboard to guess
- **Visual Hangman**: SVG-based hangman drawing that appears with each wrong guess
- **Smart Hints**: Each word comes with a helpful hint
- **Win Animation**: Colorful confetti celebration when you win
- **Share Results**: Copy emoji-rich results to clipboard with game statistics
- **How to Play Guide**: Complete instructions in an elegant modal
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Polished UI**: Beautiful gradient backgrounds, smooth animations, and modern design

## 📁 Files

The game is available in two formats:

1. **Standalone Version** (`index.html`): Complete single-file version with inline CSS and JavaScript
2. **Modular Version**: Separate files for better organization
   - `index-modular.html`: HTML structure
   - `styles.css`: All styling and animations
   - `script.js`: Game logic and interactivity

## 🚀 How to Play

1. Open `index.html` or `index-modular.html` in any modern web browser
2. A random cloud computing term will be selected
3. Click letters or use your keyboard to guess
4. Each correct letter reveals its position(s)
5. Each wrong guess adds a part to the hangman (6 attempts total)
6. Win by revealing all letters before the hangman is complete!

### Tips:
- Start with common vowels (A, E, I, O, U)
- Read the hint for guidance
- Think about cloud computing terminology

- Word revealed
- Attempts used
- Visual emoji representation
- Current game URL
